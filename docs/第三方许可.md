# 模型与开源许可

## 识别模型 slider.onnx

- 来源：开源项目 captcha-recognizer（作者 chenwei-zhao，https://github.com/chenwei-zhao/captcha-recognizer）随包分发的通用滑块缺口检测模型，YOLOv8-seg 导出为 ONNX，固定输入 640×640，单类别 `s`（滑块/缺口拼图块）。
- 许可：MIT（随上游项目许可）。
- 体积：约 38.7MB；随包分发于模块 `x64/slider.onnx`，构建时平铺复制到输出目录。
- 训练数据由上游作者收集训练，本模块只做推理封装，未做再训练。

## onnxruntime 运行库

- 来源：微软官方 NuGet 包 Microsoft.ML.OnnxRuntime 1.31.0（https://github.com/microsoft/onnxruntime）。
- 文件：`x64/onnxruntime.dll`（约 17.3MB）与 `x64/onnxruntime_providers_shared.dll`，CPU 执行提供程序。
- 许可：MIT（包内 LICENSE 文件同款）；版权版权归 Microsoft Corporation 等上游贡献者。
- 链接方式：动态链接（onnxruntime.lib 导入库 + 运行时 DLL 随包分发），符合 MIT 对再分发的全部要求。

## 图片解码

- `include/stb_image.h`：public domain / MIT 双许可（作者 Sean Barrett），只使用未修改的原文件，用于 PNG/JPG/BMP 内存解码。

## 本模块代码

- `src/captcha_gap_bridge.cpp` 由 LingBuilder 项目编写，MIT 许可。
- 推理管线（letterbox / NMS / scale_boxes）移植自 captcha-recognizer 的 `slider.py`（MIT），已按 C++ 语义重写。
